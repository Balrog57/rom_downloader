# AGENTS.md

## Commands

```powershell
# Compile-check all Python files
$files = @("main.py") + (Get-ChildItem src,tests -Recurse -Filter *.py | ForEach-Object { $_.FullName }); python -m py_compile @files

# Run tests (standalone scripts, NOT pytest)
python tests\smoke_checks.py
python tests\core_helper_checks.py
python tests\download_single_checks.py
python tests\dat_coverage_checks.py

# Quick sanity checks
python main.py --version
python main.py --sources
python main.py --diagnose

# Build portable EXE
pyinstaller --noconfirm --clean ROMDownloader.spec
dist\ROMDownloader.exe --version

# Prepare a release (version bump + compile-check + tests + git tag)
.\release.ps1 -Version "0.1.5" -Push
```

There is no pytest. Each test script has a `main()` function, inserts the project root into `sys.path`, and raises `SystemExit` on failure. No test framework.

## Architecture

- **Entry point**: `main.py` → `src.cli.main()` → `src.core.main_entry.main()` → dispatches to `src.core.cli.cli_mode` (CLI), `src.core.gui.gui_mode` (GUI), or `src.core.web_ui.run_web_ui` (Web UI).
- **`src/core/`**: ~40 modules split from an old monolith. `_facade.py` star-imports every submodule and re-exports everything. Adding a public function to any `src/core/` module makes it available as `from src.core import func` — no extra wiring. Deprecated cache wrappers in `_facade.py` delegate to `src/network/cache.py`; prefer `src/network/` for new code.
- **`src/network/`**: Isolated networking (sessions, circuit breakers, caches, async search, download/search pools, Cloudflare detection).
- **`src/providers/`**: `ProviderAdapter` dataclasses wrapping source config dicts. **The callbacks (`resolve_func`, `download_func`) are never populated** — dispatch happens via `source['type']` conditionals in `src/core/search_pipeline.py` and `src/core/download_orchestrator.py`. Provider modules (`minerva.py`, `archive_org.py`, `premium.py`) are thin re-exports from `src.core`.
- **`src/pipeline.py` + `src/progress.py`**: Top-level pipeline summary and progress helpers (not inside `core/`).

## Key conventions

- Codebase language is **French**: comments, docstrings, user-facing strings, error messages, CLI flags.
- `libtorrent` and `tkinterdnd2` are optional. `libtorrent` may fail to import on Windows without OpenSSL 1.1 DLLs (`LIBTORRENT_DLL_DIR` in `.env`). The app degrades gracefully.
- **ROM_DATABASE global**: Never do `from .rom_database import ROM_DATABASE` — that captures a stale `None`. Always use `from . import rom_database as _rom_db` and access `_rom_db.ROM_DATABASE` live, guarded by `if _rom_db.ROM_DATABASE is None: load_rom_database()`.
- Integration/network test files are **gitignored** (`test_integration_*.py`, `test_network_modules.py`). Don't try to add them to CI.
- `requirements.txt` uses compatible-release pins (`requests>=2.31,<3`). `requirements-lock.txt` is `pip freeze` snapshot for CI.
- `ROMDownloader.spec` **excludes `libtorrent`** from PyInstaller builds (avoids OpenSSL DLL issues in the portable EXE).

## Runtime requirements

- `.rom_downloader.sqlite` is the local catalog/download database, generated by `python main.py --index-catalog`, ignored by Git.
- `dat/` subdirectories (`no-intro/`, `redump/`, `retool - french no unl/`) are section headers in the GUI DAT selector, not selectable items.
- `.env` holds API keys and LoLROMs browser config. Copy from `.env.example`. Never commit `.env`.
- `aiohttp` is required for async listing pre-fetch. If missing, the app falls back to sync scraping transparently.

## Reports & audit

- `write_download_reports(output_folder, summary, formats=("txt",))` in `src/core/reports.py` generates txt/json/csv/html from a summary dict. Returns `dict[str, str]` mapping format to path.
- `write_download_report()` (singular, backward compat) delegates to `write_download_reports()` with `formats=("txt",)` and returns just the TXT path string.
- `build_report_payload(summary)` produces the stable JSON payload used by all formats: `metadata`, `counts`, `sizes`, `sources`, `items`, `extras`.
- CLI: `--report-formats txt,json,csv,html` (default `txt`), `--report-dir <dossier>` (default output folder). Works with `--dry-run`, `--analyze`, and regular downloads.
- GUI: "Audit uniquement (dry-run, aucun fichier ROM ecrit)" checkbox persists in preferences, sets `dry_run=True`, and generates TXT/JSON/CSV/HTML reports through `write_download_reports()`.

## Versioning

- Version lives in `VERSION` (SemVer), read by `--version`, GUI, and release workflow.
- CI runs on `windows-latest` with Python 3.13. `release.ps1` handles version bump + compile-check + tests + git tag; CI builds and validates the portable EXE.

## Source types & provider ordering

- `DDL_SOURCE_TYPES`: `planetemu`, `romhustler`, `coolrom`, `romsxisos`, `nopaystation`, `hshop`, `vimm`, `lolroms`, `retrogamesets`, `startgame`, `archive_org_collection`.
- `ONEFICHIER_SOURCE_TYPES`: `retrogamesets`, `startgame` (require 1fichier premium API key).
- `GENERIC_FALLBACK_SOURCE_TYPES`: `archive_org`, `minerva` (last resort).
- `build_provider_registry()` runs `prepare_sources_for_profile()` first, which adjusts priorities based on DAT profile and API key availability. Sources are sorted by `(order, priority, name.lower())`.

## SYSTEM_MAPPINGS & name resolution

- `SYSTEM_MAPPINGS` (in `src/core/sources.py`) maps DAT system names to provider-specific slugs (lolroms, vimm, edgeemu, planetemu, etc.). LoLROMs paths use exact site directory names (e.g. `'Nintendo - Game Boy Advance'`, `'SEGA/Mega Drive'`).
- `resolve_system_mapping()` tries explicit lookup, then hardcoded aliases, then **iteratively strips parenthetical suffixes** (like `(Headered)`, `(Retool)`, dates) and retries. This is how it handles DAT names without exact `SYSTEM_MAPPINGS` entries.
- CDRomance has been fully removed (site dead since January 2026).

## LoLROMs & Cloudflare

- **Three-tier bypass** (`src/core/scrapers.py`): cloudscraper session → warmup visits (root + directory page) → Playwright headless browser fallback (Edge/Chromium) for `.7z` files blocked by Cloudflare.
- Module-level globals (`LOLROMS_SESSION`, `_LOLROMS_DOWNLOAD_COUNT`, `_LOLROMS_LAST_DOWNLOAD_TS`) track rate-limiting state.
- `LOLROMS_SUBDIR_ALIASES` defines GBA subdirectories (`Multi-Boot`, `eReader`, `Video`, `Play-Yan`, `Hacks (Color)`, `T-En`). Other systems have empty subdir dicts.
- Files are `.7z` archives containing `.gba` ROMs. The download destination uses the server filename (`.7z`), not the DAT's `.gba` extension. MD5 verification iterates archive entries to compare `.gba` hashes.
- `download_file()` detects HTML content-type responses (Cloudflare challenge pages) and raises `DownloadNetworkError`.
- LoLROMs uses `delay_seconds: 3` (configurable in source policies) to avoid rate-limiting.
- **Key issue**: If `--clean-torrentzip` is not set, `.7z` files stay as `.7z`. RomVault expects `.zip`. Always run with `--clean-torrentzip` for GBA sets from LoLROMs.

## Circuit-breaker & metrics

- `SourceCircuitBreaker` trips after 10 failures, recovery 300s. Can block a provider mid-session.
- Provider stats in `.rom_downloader_preferences.json` track `attempts`, `downloaded`, `failed`, `skipped`, `dry_run`, `quota_skipped`, `seconds` per provider.
